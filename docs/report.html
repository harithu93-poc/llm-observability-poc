Key finding

A single Phi-4 (14B) request measured 27.8s at only 3.4 tok/s — the 4GB VRAM Quadro T1000 can't fit the model, so Ollama falls back to CPU. Llama 3.2 (3B) fits comfortably and stays GPU-accelerated. This is the real finding: most self-hosted LLM deployments are hardware-constrained, not just "bigger model = slower."
